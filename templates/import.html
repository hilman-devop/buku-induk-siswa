2. Import file Excel

Kunci: NIS. NIS yang sudah ada akan diperbarui, yang baru akan ditambahkan.

Kolom wajib: NIS, MAPEL, SEMESTER, NILAI. NIS harus sudah ada di data siswa.

Catatan format

  • Baris pertama file harus berisi judul kolom. Nama kolom dibaca fleksibel (mis. NO INDUK = NIS, JK = JENIS KELAMIN).
  • Tanggal lahir boleh format 2026-01-13, 13/01/2026, atau format tanggal Excel.
  • Baris tanpa NIS/Nama dilewati, tidak menggagalkan seluruh import.
  • Data lama tidak terhapus oleh import — hanya ditambah atau diperbarui.
